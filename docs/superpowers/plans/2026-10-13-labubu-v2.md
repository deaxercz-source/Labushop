# Labubu v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Přepsat `index.html` na jednoduchou appku se 3 záložkami (Lidé, Výdaje, Přehled), světlým vzhledem a stávajícími daty.

**Architecture:** Jeden soubor `index.html`, vanilla JS (`var`/`function`), Firebase compat. Čisté pomocné funkce (`bonusSite`, `bonusGifts`, `filterBonuses`, `totals`) jsou odděleny od renderu, aby šly ověřit v konzoli. Render přes `innerHTML` s `esc()` na všech uživatelských řetězcích.

**Tech Stack:** HTML/CSS/JS, Firebase 9.23.0 compat (auth + firestore), Chart.js 4.4.0, Outfit font.

**Spec:** `docs/superpowers/specs/2026-10-13-labubu-v2-design.md`

## Global Constraints

- Jeden soubor `index.html`, žádný build, žádný framework.
- Dokument `labubu/{uid}`; ukládat `db.doc(DB_DOC).set(data)` s celým načteným objektem (neznámá pole `sites`, `costs` se zachovají). Před uložením nic nemazat.
- Stavy bonusu: `pending|ordered|wait|done` (⏳ Čeká, 📦 Objednáno, 🕐 Na vyzvednutí, ✅ Předáno).
- Typy dárků: `labubu`, `dumpling`; položka `{type, qty}`.
- UI česky. Světlé pozadí, jedna zelená akcentová barva, font Outfit.
- Zachovat Firebase config, přihlášení email/heslo, `initData`/`save` (debounce 500 ms), PWA meta.
- Inputy, do kterých se píše během re-renderu, nesmí ztratit hodnotu (vyhledávací pole se nerenderuje znovu).

## Review Focus

- Starý bonus bez `gifts`, jen s `gift`+`qty` → zobrazit jako jeden dárek.
- Starý bonus se `siteId` na neexistující/smazanou stránku → „Kde“ = „—“, nespadnout.
- Bonus bez `date` nebo s `amount` jako řetězcem → neukáže `NaN`, počítá se jako číslo.
- Poznámka s `personId` smazaného člověka → zobrazí se jako obecná, nespadne.
- Prázdná data (nový účet) → každá záložka ukáže prázdný stav, graf se nerozbije.
- Jméno/poznámka obsahující `<script>` nebo `"` → vykreslí se jako text (escape).
- Smazání člověka smaže i jeho bonusy a poznámky s potvrzením.

### Task 2: Datové pomocné funkce

**Files:**
- Modify: `index.html` (sekce `// ── HELPERS ──`)

**Interfaces:**
- Produces:
  - `bonusSite(b): string` — `b.site` pokud je, jinak název z `data.sites` podle `b.siteId`, jinak `'—'`.
  - `bonusGifts(b): {type:string, qty:number}[]` — `b.gifts` pokud neprázdné pole, jinak `b.gift ? [{type:b.gift, qty:b.qty||1}] : []`.

  - `filterBonuses(list, f): bonus[]`, `f = {q, status, range:'all'|'month'|'30'|'7', site}`; `q` hledá ve jménu člověka.

- [ ] **Step 2:** Implementovat funkce podle signatur výše.
